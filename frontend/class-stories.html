운영 흐름

후기와 사진은 초안으로 모으고, 공개는 승인 후 진행

1. 후기 접수

운영자가 보낸 후기 작성 링크로 수강생이 직접 후기를 남깁니다.

2. 개인정보 확인

얼굴, 이름, 연락처, 계정 화면, 토큰이 보이면 공개 전에 가립니다.

3. 강사/일정별 정리

강사, 일정, 주제, 공개 상태로 필터링해 사람이 많아져도 관리합니다.

4. 승인 후 공개

관리자가 문구를 확인한 카드만 이 공개 후기보드에 노출합니다.
