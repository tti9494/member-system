구매 신청

신청이 접수되면 운영자가 결제 안내를 확인한 뒤 라이선스를 발급합니다. 라이선스 키는 발급 순간 한 번만 표시되며, 고객에게 직접 안내합니다.

1

구매 신청을 남기고 결제 안내를 확인합니다.

2

관리자가 입금 또는 결제 상태를 확인합니다.

3

확인된 주문에 라이선스를 발급하고 Windows YOONBOT에 입력합니다.

4

처음 등록한 PC 기준으로 activate/verify가 진행됩니다.

환불, 취소, 기기 변경

라이선스 발급 전 취소는 운영자 확인 후 처리합니다. 발급 후 환불은 사용 상태와 기간을 확인해 별도 안내합니다. PC 교체가 필요한 경우 관리자 기기 초기화 후 새 PC에서 다시 인증합니다.

FAQ

자동 결제인가요?

현재는 수동 결제 확인 방식입니다. PG 연동 전까지 운영자가 결제 확인 후 라이선스를 발급합니다.

키를 여러 PC에서 쓸 수 있나요?

기본 라이선스는 1대 PC 기준입니다. 다른 PC에서 사용하려면 기기 초기화가 필요합니다.

라이선스 서버 주소는 무엇인가요?

Windows YOONBOT 운영 설정의 LICENSE_API_URL은 https://apply.arsen-ai.com입니다.
