운영자 인증

관리자 비밀번호를 입력해야 운영 화면을 볼 수 있습니다.

무료 신청 기본 신청 유료 신청 수업용 대시보드 후기 공개 YOONBOT 운영 상세 Lab (A2) 주문 관리 라이선스
관리자 비밀번호는 운영 환경에 고정 등록된 값입니다. 보안을 위해 실제 값은 화면에 표시하지 않습니다.
기본값은 현재 브라우저 탭에만 임시 저장입니다. 외부에서 자주 볼 기기라면 “이 기기에서 기억”을 켜세요.
로컬 테스트 DB 현재 화면은 이 Mac의 테스트 전용 DB를 보고 있습니다. 운영 웹사이트 데이터가 아니므로 테스트 계정, 블랙리스트, 삭제된 검증 데이터가 보일 수 있습니다.

테마 적용 전 확인
전체 백업을 먼저 남기세요. 코드 스냅샷, 공개 홈페이지 파일, 관리자 파일, D1 DB export를 함께 보관하는 방식이 안전합니다.
단순 CSS 테마 변경은 상담/강의 신청/예약 확인/텔레그램/DB 저장 기능을 바꾸지 않습니다.
새 테마에서 HTML을 통째로 교체할 때는 data-consultation-form, 필드 name, data-success, data-error, assets/site.js 연결을 유지해야 합니다.
적용 전 미리보기에서 홈, 강의 신청, 무료/유료 신청, 예약 확인, 상담, YOONBOT 상세, 관리자 화면을 확인하세요.
