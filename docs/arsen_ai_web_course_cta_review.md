# arsen-ai.com 강의 / 컨설팅 CTA 검토 초안

## 목적

공개 홈페이지에 바로 반영하지 않고, 먼저 상욱님이 검토할 수 있는 모집 문구와 신청 흐름을 정리합니다.

## 상품명 후보

1. AI 기초 셋팅 및 컨설팅 강의 1:4
2. AI 업무 자동화 입문반
3. AI 시스템 설계 4주 플랜

## 첫 화면 문구 후보

### 제목

AI 도구를 설치하는 데서 끝나지 않고, 내 업무에 맞는 자동화 흐름까지 설계합니다.

### 설명

ChatGPT, Claude, Gemini 같은 AI 도구를 처음 쓰는 분부터, 실제 업무 자동화나 협업 시스템을 만들고 싶은 분까지 함께 진행하는 소규모 실습형 강의입니다.  
기초 설정, 유료 구독 점검, 프롬프트 구조, 구현하고 싶은 업무 흐름 설계까지 1:4 형태로 진행합니다.

## 운영 정보

| 항목 | 내용 |
|---|---|
| 대상 | AI 초보자, 자영업자, 강사, 기획자, 개발자, 업무 자동화가 필요한 직장인 |
| 형태 | 오프라인 소규모 1:4 강의 / 컨설팅 |
| 장소 | 영등포시장역 사무실, 서울 공유오피스, 안양 공유오피스 |
| 기본 시간 | 일요일 10:00-12:00 / 13:00-15:00 / 16:00-18:00 |
| 정원 | 타임당 4-5명 |
| 가격 | 1회 50,000원 |
| 확장 상품 | 컨설팅 및 구현화 4주 플랜 |

## 준비물

- 노트북
- 필기구
- ChatGPT 또는 Claude 유료 구독 권장
- 구현하고 싶은 업무나 아이디어 1가지
- 현재 AI 사용 중 막힌 지점

6. 강의 전 준비 안내

## 공개 반영 전 확인할 것

- 결제 방식 문구 확정
- 환불 / 일정 변경 규칙
- 장소별 실제 주소 공개 범위
- 신청자 개인정보 안내 문구
- 홈페이지 톤: 공개 마케팅용 / 스터디 멤버용 중 선택

## 현재 구현 연결

member-system에는 아래 흐름이 먼저 구현됩니다.

- 공개 일정 조회: `GET /sessions`
- 신청서 일정 선택: `session_id`
- 예약 신청 저장: `bookings`
- 관리자 일정 생성: `POST /admin/sessions`
- 관리자 입금 / 확정 상태 변경: `POST /admin/bookings/{booking_id}/state`
